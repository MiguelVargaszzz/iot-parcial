# Datasets

Descarga estos dos CSV y déjalos en esta carpeta con estos nombres exactos:

1. **AirQualityUCI.csv**: UCI Machine Learning Repository, dataset "Air Quality".
   Busca "UCI Air Quality dataset" y descarga el zip; adentro viene `AirQualityUCI.csv` (separado por `;`, decimales con `,`).
2. **energydata_complete.csv**: UCI Machine Learning Repository, dataset "Appliances energy prediction".

Si falta algún archivo, ese dispositivo no publica y el resto sigue funcionando.
